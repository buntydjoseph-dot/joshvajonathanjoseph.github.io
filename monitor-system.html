Current collaborative project

AI-enabled monitoring and control system

The concept uses sensor nodes placed around a monitored area and connects them to a central concentrator. The concentrator gathers data, coordinates local automation and supports analysis or prediction without depending entirely on continuous internet access.

  • Distributed environmental and equipment sensor nodes
  • LoRa or wired communication to a central concentrator
  • Embedded Linux gateway for coordination and data handling
  • Local control of pumps, fans, motors, relays and alarms
  • Structured data collection and predictive analysis
