IoT Environmental Monitoring System

A portfolio-ready IoT system where an ESP32 reads BMP280 environmental sensor data, publishes telemetry through MQTT, and a Raspberry Pi embedded Linux gateway runs a Python MQTT bridge to forward data to a HiveMQ cloud broker for browser-based monitoring and remote command control.

System Architecture

Accurate flow based on the project: sensor node, Linux gateway, MQTT bridge, cloud broker and web dashboard.

🌡️

BMP280 Sensor

Measures temperature and pressure for environmental monitoring.

📟

ESP32 Device

Reads BMP280 values and publishes telemetry to a local MQTT topic.

🐧

Raspberry Pi Gateway

Runs embedded Linux, Mosquitto and a Python MQTT bridge for cloud communication.

☁️

HiveMQ Broker

Cloud MQTT broker carries telemetry and command messages using JSON payloads.

🖥️

Web Dashboard

Displays sensor values, connection status, logs and remote control buttons.
