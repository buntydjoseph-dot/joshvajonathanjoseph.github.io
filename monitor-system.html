IoT Environmental Monitoring System

A real IoT monitoring build where an ESP32 reads BMP280 temperature and pressure data, publishes telemetry through MQTT, and a Raspberry Pi embedded Linux gateway uses a Python MQTT bridge to forward data to a cloud broker for browser-based monitoring and remote command control.

System Architecture

Accurate flow based on the project: ESP32 sensor node, Raspberry Pi Linux gateway, Python MQTT bridge, cloud broker and browser dashboard.

BMP280 Sensor
