IoT Environmental Monitoring System

An end-to-end IoT monitoring project using an ESP32 with a BMP280 sensor, a Raspberry Pi embedded Linux gateway, Mosquitto, a Python MQTT bridge, HiveMQ cloud MQTT, and a browser dashboard for real-time temperature, pressure, system status visualisation, and remote command control.

System Architecture

Sensor → ESP32 → Local MQTT → Raspberry Pi Bridge → HiveMQ → Dashboard
🌡️

BMP280 Sensor

Measures temperature and pressure for environmental monitoring.

📟

ESP32 Device

Reads BMP280 data and publishes telemetry through MQTT.

🐧

Raspberry Pi Gateway

Runs embedded Linux, Mosquitto, network setup, topic debugging, and the Python MQTT bridge.

☁️

HiveMQ Cloud Broker

Transfers telemetry and command messages between the gateway and dashboard.

🖥️

Web Dashboard

Shows live values, MQTT status, packet count, and fan or relay commands.

What I Built

Project implementation

Python MQTT Bridge

Bridged local sensor telemetry from the Raspberry Pi and Mosquitto side to HiveMQ cloud MQTT, and subscribed to command topics for device-side control.

Embedded Linux Workflow

Worked with SSH access, network setup, broker testing, MQTT topic debugging, and service-level troubleshooting on Raspberry Pi.

End-to-End Testing

Validated data flow and command response across ESP32, Linux gateway, cloud MQTT broker, and the web dashboard.
