Sentinel: Custom Embedded Linux & System Monitor

This repository contains the source code and build system integration files for Sentinel, a custom Embedded Linux distribution and system monitoring application.

Instead of relying on a pre-built OS (like Raspberry Pi OS or Ubuntu), this project demonstrates a full-stack embedded approach: building a highly optimized, lightweight Linux operating system from scratch using Buildroot, and integrating a custom-written C application directly into the system's root filesystem.

System Architecture

The project is divided into two major components, seamlessly integrating user-space application code with a custom cross-compiled OS.

1. The Sentinel Application (/sentinel_source)

  • A C-based system monitoring program designed for low-overhead execution.
  • Interfaces directly with the Linux Kernel (via the /proc filesystem) to acquire real-time system load, memory, and performance metrics.
  • Implements a custom TCP/IP socket server from scratch to transmit diagnostic data over the network via a lightweight, HTTP-compatible protocol.
  • Manages custom logging via low-level POSIX system calls (open, read, write).

2. The OS Build System (/buildroot_integration & defconfig)

  • Uses Buildroot to cross-compile the target OS, complete with a custom Linux Kernel, ext4 root filesystem, and BusyBox toolchain.
  • Custom Config.in and Makefiles (.mk) seamlessly inject the Sentinel C code into the automated build pipeline.
  • Resolves architecture mismatches to ensure the host-developed C code is properly cross-compiled for the specific target execution environment.
